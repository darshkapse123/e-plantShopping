# e-plantShopping

## Project Description
e-plantShopping is an online plant shopping application where users can
browse different categories of houseplants, add plants to their shopping
cart, update quantities, and view their total purchase amount.

## Features
- Browse multiple categories of houseplants
- View plant images, names, and prices
- Add plants to the shopping cart
- Increase or decrease item quantities
- Remove plants from the cart
- View the total cart amount
