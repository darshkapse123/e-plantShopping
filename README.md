# Paradise Nursery

## Project Description

Paradise Nursery is an online plant shopping application built using React. It allows users to browse different categories of houseplants, view plant details, and add their favourite plants to a shopping cart.

## Features

- Browse houseplants across different categories.
- View plant names, images, descriptions, and prices.
- Add plants to the shopping cart.
- Increase or decrease product quantities.
- Remove products from the cart.
- View dynamically updated cart totals.
- Navigate between Home, Plants, and Cart pages.

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Redux Toolkit
